Como se calcula cada punto?

En cada paso evalúa la pendiente f(x, y) en cuatro lugares del intervalo [xₙ, xₙ + h] y avanza con su promedio ponderado. Las pendientes del punto medio pesan el doble.

k₁ = f(xₙ, yₙ) k₂ = f(xₙ + h/2, yₙ + (h/2)·k₁) k₃ = f(xₙ + h/2, yₙ + (h/2)·k₂) k₄ = f(xₙ + h, yₙ + h·k₃) yₙ₊₁ = yₙ + (h/6)·(k₁ + 2k₂ + 2k₃ + k₄) xₙ₊₁ = xₙ + h
